# Väder

Familjens egen väderapp – nu-läge, 24 timmar och 10 dagar för sparade orter.
Väderdata från [Open-Meteo](https://open-meteo.com/) (gratis, ingen nyckel). Designen matchar Mat-appen.

Filer: `index.html` (appen), `sw.js`, `manifest.webmanifest`, ikonerna `icon-*.png`.
Lägg alla filer i roten av ett GitHub Pages-repo. Orterna sparas i webbläsaren på varje enhet.
